# Mapa Discursivo: Red Autor–Tema

Este repositorio contiene una aplicación en **Streamlit** para analizar archivos **BibTeX** y generar:

- Red de coautoría
- Red Autor–Tema (mapa discursivo)
- Estadísticas básicas (autores, años, keywords)
- Visualización interactiva con PyVis

---

## 🚀 Requisitos

Asegúrate de tener instalado:

- Python 3.10+  
- pip  
- Git
